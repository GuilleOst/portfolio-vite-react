## 🚀 Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando herramientas modernas y optimizadas para el rendimiento:

* **Core:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Internacionalización:** [react-i18next](https://react.i18next.com/) (Soporte Bilingüe Español / Inglés)
* **Deploy:** [Vercel](https://vercel.com/)

## ⚙️ Instalación y Uso Local

Si querés clonar el proyecto para verlo o modificarlo localmente, seguí estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/GuilleOst/portfolio-vite-react.git](https://github.com/GuilleOst/portfolio-vite-react.git)
2. **Ingresar a la carpeta del proyecto:**

   ```bash
    cd portfolio-vite-react
3. **Instalar las dependencias:**

   ```bash
    npm install
4. **Ejecutar el servidor de desarrollo:**

   ```bash
    npm run dev
5. **Abrí http://localhost:5173/ en tu navegador para ver la página.**
